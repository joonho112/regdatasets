PISA 2000 reading: UK, Germany and USA

Source: R/data-pisa2000.R
pisa2000.Rd

Reading scores and family background of 4,528 15-year-old students in the United Kingdom, Germany and the United States who took part in PISA 2000, the OECD's Programme for International Student Assessment. Each row is a student, and the students come from 720 schools. The file is a three-country teaching extract of the PISA 2000 database, with derived variables defined as in Rabe-Hesketh and Skrondal's Multilevel and Longitudinal Modeling Using Stata; how its students were selected is not documented.

Usage

pisa2000

Format

A tibble with 4,528 rows and 15 variables.

country

Country. Values: "276" = Germany; "826" = United Kingdom; "840" = United States. Type: character. ISO 3166 numeric country codes, stored as text.

female

Female. Values: 0 = male; 1 = female. Type: integer.

isei

Parental occupational status (ISEI). Units: ISEI points. Type: integer. International Socio-Economic Index of occupational status of the father or mother; higher = higher-status occupation.

wleread

Reading ability estimate (WLE). Units: PISA reading scale points. Type: double. Weighted likelihood (Warm) estimate on the PISA 2000 reading scale; reading and pass_rea are derived from it.

high_sch

Highest parental education is high school. Values: 0 = no; 1 = yes. Type: integer. high_sch and college are never both 1; both are 0 for 1,529 students (the reference group).

college

Highest parental education is college. Values: 0 = no; 1 = yes. Type: integer.

one_for

One parent born abroad. Values: 0 = no; 1 = yes. Type: integer. one_for and both_for are never both 1; both 0 means neither parent was born abroad.

both_for

Both parents born abroad. Values: 0 = no; 1 = yes. Type: integer.

test_lan

Home language is the test language. Values: 0 = no; 1 = yes. Type: integer.

reading

Reading proficiency level. Values: 0 = below level 1; 1 = level 1; 2 = level 2; 3 = level 3; 4 = level 4; 5 = level 5. Type: integer. Derived from wleread: the levels start at about 335, 407, 480, 553 and 626 points (the PISA 2000 cut-points).

pass_rea

Proficient in reading (level 4 or 5). Values: 0 = level 0 to 3; 1 = level 4 or 5. Type: integer. Equals 1 exactly when reading is 4 or 5; the v0.2.0 help page wrongly said level 3 or higher.

id_schoo

School ID. Type: integer. Unique across countries: UK 1 to 520, Germany 621 to 839, US 840 to 990.

uk

United Kingdom. Values: 0 = no; 1 = yes. Type: integer. Dummy for country = "826".

germany

Germany. Values: 0 = no; 1 = yes. Type: integer. Dummy for country = "276".

usa

United States. Values: 0 = no; 1 = yes. Type: integer. Dummy for country = "840".

See codebook("pisa2000") for this table as a data frame.

Source

OECD. (2002). PISA 2000 technical report. OECD Publishing. Data: OECD PISA 2000 database. https://www.oecd.org/en/about/programmes/pisa.html

Three-country teaching extract made for the UC Berkeley EDUC 275B course, with derived variables as in Rabe-Hesketh and Skrondal (Stata Press). Provenance: probable.

Details

Coding. country holds ISO numeric country codes stored as text: "826" = United Kingdom, "276" = Germany and "840" = United States. The dummies uk, germany and usa sum to 1 in every row, so a model with an intercept can include only two of them, and the one left out is the reference; factor(country) makes Germany ("276") the reference. reading is the PISA proficiency level (0 = below level 1, up to 5), derived from wleread, and pass_rea is 1 for levels 4 and 5 only. Parental education is coded by two dummies: students with both high_sch and college equal to 0 (1,529 of them) form the reference group.

Design. Students are clustered in schools (id_schoo, unique across countries), and the file has no sampling weights. Standard errors that ignore the clustering can be too small, and the country means should not be read as national estimates. Rows 2123 and 2386 are identical on all 15 variables; whether they are two students or one duplicated record is not known. There are no missing values. Version 1.0.0 changed no values; it corrects the definition of pass_rea given in the v0.2.0 help page.

Suggested analyses.

  • simple regression of wleread on isei;

  • comparing the three countries with dummy variables (one-way ANOVA as a regression);

  • interactions, e.g. whether the isei slope or the gender gap differs by country;

  • logistic regression of pass_rea.

See also

codebook() for the variable table as a data frame, and list_datasets() for the other datasets.
