Adolescent alcohol use (person-period data)

Source: R/data-alcohol1_pp.R
alcohol1_pp.Rd

Alcohol use of 82 adolescents, each measured at ages 14, 15 and 16, in person-period (long) format: one row per adolescent per age, 246 rows in all. Besides an alcohol-use score, the data record whether the adolescent is a child of an alcoholic parent, the adolescent's gender and a score for alcohol use among the adolescent's peers. They are example data from Singer and Willett's (2003) book Applied Longitudinal Data Analysis.

Usage

alcohol1_pp

Format

A tibble with 246 rows and 9 variables.

id

Adolescent ID. Type: integer. 82 adolescents, each observed at ages 14, 15 and 16 (3 rows per person).

age

Age at measurement. Units: years. Type: integer.

coa

Child of an alcoholic parent. Values: 0 = no; 1 = yes. Type: integer. Constant within person (37 of the 82 adolescents are 1).

male

Male. Values: 0 = female; 1 = male. Type: integer. Constant within person.

age_14

Age minus 14. Units: years. Type: integer. Time variable centered at age 14 (0 = age 14).

alcuse

Alcohol use score. Units: scale score. Type: double. Higher = more alcohol use. Every value is the square root of a whole number from 0 to 13; how the score was built is not documented in the package sources.

peer

Peer alcohol use score. Units: scale score. Type: double. Higher = more alcohol use among peers. Constant within person, so not time-varying; its construction is not documented in the package sources.

cpeer

Peer alcohol use, centered. Units: scale score. Type: double. Equals peer minus 1.018, the sample mean of peer.

ccoa

Child of an alcoholic, centered. Values: -0.451 = not a child of an alcoholic (coa = 0); 0.549 = child of an alcoholic (coa = 1). Type: double. Equals coa minus 0.451, the sample mean of coa.

See codebook("alcohol1_pp") for this table as a data frame.

Source

Singer, J. D., & Willett, J. B. (2003). Applied longitudinal data analysis: Modeling change and event occurrence. Oxford University Press. https://stats.oarc.ucla.edu/other/examples/alda/

Companion data of the book, distributed by UCLA OARC; reached the package through the UC Berkeley EDUC 275B course files. Provenance: verified.

Details

Design. Every adolescent has exactly three rows, one per age, and no value is missing. age_14 (age minus 14) is the time variable, so 0 is age 14. Only age, age_14 and alcuse vary within an adolescent: coa, male and peer (and the centered ccoa and cpeer) are the same in all three rows. peer is therefore a person-level predictor, not a time-varying one.

Scores. How alcuse and peer were constructed is not documented in the package sources, so their units are unknown; higher values mean more alcohol use. Every alcuse value is the square root of a whole number from 0 to 13. Check Singer and Willett (2003) before giving the scores a substantive meaning.

Centered variables. cpeer is peer minus 1.018 and ccoa is coa minus 0.451, the sample means rounded to three decimals. In alcuse ~ age_14 * cpeer, centering changes the intercept and the age_14 coefficient (now the age slope at the mean peer score), but the cpeer and interaction coefficients are the same as with peer.

The values are unchanged in version 1.0.0.

Suggested analyses.

  • Linear change in alcuse over age_14, with intercept and slope allowed to differ by coa (alcuse ~ age_14 * coa): an interaction between a dummy and a continuous predictor.

  • Centering: compare alcuse ~ age_14 * peer with alcuse ~ age_14 * cpeer.

  • Multilevel growth models with a random intercept and a random age_14 slope for each id (for example with the lme4 or nlme package). Ordinary regression on the 246 rows treats the three rows of an adolescent as independent, so its standard errors cannot be trusted.

See also

codebook() for the variable table as a data frame; list_datasets(), for example list_datasets(topic = "multilevel-longitudinal") for other datasets with nested or repeated measurements.

#> 5     2    15     1     1      1   0    0.894 -0.124 0.549

# Three rows per adolescent (ages 14, 15 and 16)
table(table(alcohol1_pp$id))
#> 
#>  3 
#> 82 

# Does the age trend differ for children of alcoholics (coa = 1)?
# (OLS ignores the dependence among each adolescent's three rows.)
coef(lm(alcuse ~ age_14 * coa, data = alcohol1_pp))
#> (Intercept)      age_14         coa  age_14:coa 
#>  0.31595172  0.29295517  0.74321203 -0.04942994 

# Centered peer score: age_14 is now the age slope at the mean peer score
coef(lm(alcuse ~ age_14 * cpeer, data = alcohol1_pp))
#>  (Intercept)       age_14        cpeer age_14:cpeer 
#>    0.6516377    0.2705847    0.7587719   -0.1513771
