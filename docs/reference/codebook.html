Codebook of a dataset

Source: R/codebook.R
codebook.Rd

Returns the variable-level documentation of one dataset: label, type, meaning of every code, units, the number of missing values, and which codes of the source file were recoded to NA, with the number of cells. It is the same table that generates the dataset's help page, in a form you can filter and print.

Usage

codebook(dataset)

Arguments

dataset

The name of a dataset, as a string, e.g. "nels_data". See list_datasets() for the names.

Value

A tibble (with subclass regdatasets_codebook) containing one row per variable and columns variable, label, type, values, units, group, na_count, recoded_to_na and notes.

Details

When printed in the console, empty (all-NA) metadata columns are hidden so that value meanings and notes stay readable; all nine columns remain in the returned tibble. For wide datasets such as nels_data, filter by label or group or inspect with View(codebook("nels_data")).

Examples

codebook("titanic")
#> # A tibble: 6 × 7
#>   variable label               type      values             units na_count notes
#>   <chr>    <chr>               <chr>     <chr>              <chr>    <int> <chr>

#> 2 survived Survived            integer   0 = died; 1 = sur… NA           0 NA   
#> 3 age      Age                 double    NA                 years      263 Frac…
#> 4 fare     Passenger fare      double    NA                 pre-…        1 17 p…
#> 5 embarked Port of embarkation character C = Cherbourg; Q … NA           2 Corr…
#> 6 sex      Sex                 integer   0 = male; 1 = fem… NA           0 NA   
#> # Empty (all-NA) columns hidden: group, recoded_to_na 

# Find the self-concept variables in a wide dataset
cb <- codebook("nels_data")
cb[grepl("self-concept", cb$label, ignore.case = TRUE),
   c("variable", "label", "group")]
