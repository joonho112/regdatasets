Titanic passenger survival

Source: R/data-titanic.R
titanic.Rd

Survival, passenger class, sex, age, fare and port of embarkation for 1,309 passengers of the Titanic, which sank in April 1912; the crew are not included. One row per passenger. The data are 6 of the 14 variables of titanic3, compiled by Thomas Cason from Encyclopedia Titanica and other sources and distributed by the Department of Biostatistics at Vanderbilt University.

Usage

titanic

Format

A tibble with 1,309 rows and 6 variables.

pclass

Passenger class. Values: 1 = first class; 2 = second class; 3 = third class. Type: integer. A proxy for socioeconomic class.

survived

Survived. Values: 0 = died; 1 = survived. Type: integer.

age

Age. Units: years. Type: double. Fractional for infants under 1 year. 263 passengers (20%) have no age.

fare

Passenger fare. Units: pre-1970 British pounds. Type: double. 17 passengers have a fare of 0 and 1 is NA.

embarked

Port of embarkation. Values: C = Cherbourg; Q = Queenstown; S = Southampton. Type: character. Corrected from the titanic3 source in v1.0.0 (355 passengers were wrong in the course file). 2 passengers are NA.

sex

Sex. Values: 0 = male; 1 = female. Type: integer.

See codebook("titanic") for this table as a data frame.

Source

Cason, T. (1999). titanic3 (Data set). Department of Biostatistics, Vanderbilt University. Based on Encyclopedia Titanica and Eaton and Haas (1994), Titanic: Triumph and Tragedy. https://hbiostat.org/data/repo/titanic.html

Six of the 14 titanic3 variables, via the UC Berkeley EDUC 275B course files; embarked re-taken from titanic3 in 1.0.0. Provenance: verified.

Details

survived is 1 for the 500 passengers (38%) who survived. sex is coded 1 = female and 0 = male, so its coefficient compares women with men. pclass is an integer; use factor(pclass) for a separate effect of each class rather than a linear trend. fare is in pre-1970 British pounds; 17 passengers have a fare of 0 and 1 has none.

Age is missing for 263 passengers (20%), 208 of them in third class, and passengers with no recorded age survived less often (28% against 41%). Models with age drop these passengers by default, and the complete cases are not a random subset. Ages under 1 year are fractional.

Version 1.0.0 corrected embarked. In the file used by earlier versions the port was wrong for 355 passengers (27%); it is now taken from titanic3, so results that use embarked change. Two passengers have no recorded port. The other variables are unchanged.

Suggested analyses.

  • simple logistic regression of survival on sex, with odds ratios;

  • multiple logistic regression with class (as a factor) and age, and a sex-by-class interaction: 97% of first-class women survived, but only 49% of third-class women;

  • missing data: what complete-case analysis of age does to the sample;

  • logit versus probit links, and the latent-variable view of a binary outcome.

Note

Each row is a real person, and 809 of these passengers died in the sinking. The data are offered for statistical teaching, with respect for the people they describe and for their families.

See also

carData::TitanicSurvival on CRAN has the same 1,309 passengers in the same order, with four of these variables (survival, sex and class as factors, and age). The base R table datasets::Titanic is a different source: counts for 2,201 people, crew included, with age only as child or adult. codebook() and list_datasets().

with(titanic, tapply(survived, list(sex = sex, class = pclass), mean))

# Logistic regression with class as a factor
fit <- glm(survived ~ sex + factor(pclass) + age, family = binomial,
           data = titanic)
