Simulated class survey

Source: R/data-classdata_07.R
classdata_07.Rd

Simulated data for 44 imaginary students: study and work hours (actual and desired), gender, height, desired weight, exercise, sleep, alcohol use and age group. The values are a seeded, simulated look-alike of a 44-student class survey from 2007, not anyone's real answers. The original survey has no consent or release record, so version 1.0.0 replaced it with simulated values that keep its variable names, types, codes and plausible ranges.

Usage

classdata_07

Format

A tibble with 44 rows and 12 variables.

actual_study

Actual study time. Units: hours per week. Type: integer. All classdata_07 values are simulated (a seeded look-alike of a 2007 class survey), not real responses.

desired_study

Desired study time. Units: hours per week. Type: integer.

actual_work

Actual work time. Units: hours per week. Type: integer.

desired_work

Desired work time. Units: hours per week. Type: integer.

gender

Gender. Values: 0 = female; 1 = male. Type: integer.

height

Height. Units: inches. Type: double.

desired_weight

Desired weight. Units: pounds. Type: integer.

exer

Exercise. Units: hours per week. Type: double.

sleep

Sleep. Units: hours per night. Type: double.

alcohol

Alcoholic drinks. Units: drinks per week. Type: integer. The single impossible value (-1) of the original survey is not reproduced in the simulation.

overage

Overage flag (meaning not documented). Values: no = the only value in the data (meaning not documented). Type: character. Constant: no in every row. What the original survey item flagged is not documented.

age

Age group. Values: 0 = up to 27 years; 1 = 28 to 31 years; 2 = 32 years and up. Type: integer.

See codebook("classdata_07") for this table as a data frame.

Source

Simulated data (regdatasets 1.0.0), modeled on a 2007 class survey from the UC Berkeley Graduate School of Education.

Generated by a seeded simulation in data-raw/recipes/classdata_07.R; the original survey is not distributed. Provenance: verified.

Details

Simulated values. Every value comes from a seeded simulation (the script data-raw/recipes/classdata_07.R in the package's source repository), so the values are the same in every build. By construction, height and desired weight differ between women and men, desired study hours are actual study hours plus noise, and desired work hours are a fraction of actual work hours; the other variables were drawn independently. Any pattern in the data is a property of the simulation: use the data to practice methods, not to learn about real students.

Coding. gender is 0 for female and 1 for male (32 and 12 rows). age is an age group (0 = up to 27, 1 = 28 to 31, 2 = 32 and up), not years. overage is "no" in every row; what the original survey item recorded is not documented. Because overage is a single-level character column, exclude it when using dot formulas (for example, lm(height ~ . - overage, data = classdata_07)). No value is missing.

Suggested analyses.

  • A two-sample t-test and a regression on a 0/1 dummy are the same test: t.test(height ~ gender, var.equal = TRUE) and lm(height ~ gender) give the same t statistic (up to its sign) and p-value, and the dummy's coefficient is the difference between the two group means.

  • Simple regression, for example of actual_study on desired_study.

  • A dummy and a continuous predictor together, for example desired_weight ~ height + gender: height predicts desired weight on its own but not once gender is controlled, because the simulation links the two only through gender.

See also

codebook() and list_datasets().
