List the datasets in regdatasets

Source: R/list_datasets.R
list_datasets.Rd

Returns one row per dataset with its title, dimensions, regression topics and a one-sentence description. The information comes from the package registry, the same source that generates the help pages and README, so it always matches the data.

Usage

list_datasets(topic = NULL)

Arguments

topic

Optional. Keep only datasets tagged with this topic, one of "simple-regression", "ancova", "anova", "continuous-predictors", "interactions", "nonlinear", "model-building", "diagnostics", "logistic", "glm-latent", "ordinal", "multilevel-longitudinal".

Value

A tibble (with subclass regdatasets_list) with columns dataset, title, rows, cols, topics and description.

See also

codebook() for the variables of one dataset.
