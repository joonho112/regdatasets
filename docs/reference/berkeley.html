Berkeley graduate admissions: five departments

Source: R/data-berkeley.R
berkeley.Rd

Admission decisions for the 3,593 applicants to five departments of the graduate school of the University of California, Berkeley, in fall 1973, one row per applicant. Departments 1 to 5 are departments B to F of the admissions table in base R's datasets::UCBAdmissions, which identifies departments only by letter; department A is not included. The data are a classic example of confounding and Simpson's paradox in logistic regression.

Usage

berkeley

Format

A tibble with 3,593 rows and 3 variables.

department

Department. Values: 1 = department B; 2 = department C; 3 = department D; 4 = department E; 5 = department F. Type: integer. Letters are the anonymous departments of datasets::UCBAdmissions; department A (933 applicants) is not included.

female

Female applicant. Values: 0 = male; 1 = female. Type: integer.

admitted

Admitted. Values: 0 = rejected; 1 = admitted. Type: integer. One row per applicant (fall 1973), expanded from the published admissions table, so many rows are identical.

See codebook("berkeley") for this table as a data frame.

Source

Bickel, P. J., Hammel, E. A., & O'Connell, J. W. (1975). Sex bias in graduate admissions: Data from Berkeley. Science, 187(4175), 398-404. doi:10.1126/science.187.4175.398

Via Agresti and Finlay, Statistical Methods for the Social Sciences (exercise data), and the UC Berkeley EDUC 275B course files. Provenance: verified.

Details

Departments. department is a code: 1 = B, 2 = C, 3 = D, 4 = E and 5 = F. Department A (933 applicants) is absent, so the data hold 3,593 of the 4,526 applicants in datasets::UCBAdmissions. Use factor(department) in models: entered as a number, the code would force a straight-line trend across arbitrary labels.

One row per applicant. The rows were expanded from a table of counts, so there are only 20 distinct rows (5 departments x 2 genders x 2 decisions). female is 1 for women and 0 for men, whereas berk_sub codes male. No value is missing, and the values are unchanged in version 1.0.0.

Simpson's paradox. Overall, 27% of women and 37% of men were admitted (odds ratio for women 0.64). But almost all women (1,702 of 1,727) applied to departments C to F, which admitted 6% to 35% of their applicants, while 30% of men applied to department B, which admitted 63%. Controlling for department, the odds ratio for women is about 0.97.

Suggested analyses.

  • Logistic regression of admitted on female, without and with factor(department): how adjusting for a confounder changes the gender coefficient.

  • Adding female:factor(department) gives the saturated model for the 10 department-by-gender cells. A likelihood-ratio test against it (anova(..., test = "Chisq")) asks whether the gender effect differs across departments, and is a goodness-of-fit test of the main-effects model.

See also

berk_sub for departments B and E only, coded with male; datasets::UCBAdmissions in base R for the full six-department table of counts (4,526 applicants); codebook() and list_datasets().

Examples

head(berkeley)
#> # A tibble: 6 × 3
#>   department female admitted
#>        <int>  <int>    <int>
#> 1          1      0        0
#> 2          1      1        0
#> 3          2      0        0
#> 4          2      1        0
#> 5          3      0        0
#> 6          3      1        0

# Admission rate by department (rows) and gender (columns, female = 1)
with(berkeley, tapply(admitted, list(department, female), mean))
#>            0          1
#> 1 0.63035714 0.68000000
#> 2 0.36923077 0.34064081
#> 3 0.33093525 0.34933333
#> 4 0.27748691 0.23918575
#> 5 0.05898123 0.07038123

# Odds ratio for women, before and after controlling for department
fit0 <- glm(admitted ~ female, data = berkeley, family = binomial)
fit1 <- glm(admitted ~ female + factor(department), data = berkeley,
            family = binomial)
exp(coef(fit0)["female"])
#>    female 
#> 0.6394079 
exp(coef(fit1)["female"])
#>    female 
#> 0.9697744
