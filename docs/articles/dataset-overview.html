Changed in version 1.0.0

In addition to stripping legacy Stata attributes across all datasets and removing lambert and civic_ed (no redistribution basis), six shipped datasets changed values or columns in version 1.0.0:

Dataset Version Summary of value/column changes
classdata_07 1.0.0 Replaced with a seeded simulated look-alike (no consent record for the 2007 survey).
disc 1.0.0 144 remaining nonresponse codes recoded to NA; race gained ‘American Indian’ (68 students).
disc2 1.0.0 race gained ‘American Indian’ (68 students).
gcse 1.0.0 Removed the stored model-prediction column pred (6 -> 5 columns).
nels_data 1.0.0 41,966 nonresponse, composite missing, and ordered ‘don’t know’ codes recoded to NA.
titanic 1.0.0 Corrected embarked from titanic3 (355 passengers: 353 changed, 2 to NA).

See NEWS.md for the full migration table.
