Getting started with regdatasets

Source: vignettes/getting-started.Rmd
getting-started.Rmd

Install 

# install.packages("remotes")
remotes::install_github("joonho112/regdatasets")

# A fixed release keeps every number in a course stable:
remotes::install_github("joonho112/regdatasets@v1.0.0")

Understand the variables

Every dataset has a help page, for example ?gcse. The variable table on that page is also available as a data frame through codebook(), which hides empty columns when printed so value meanings stay readable. For wide datasets, filter by label or group, or inspect interactively with View(codebook("nels_data")):

Use the data

The datasets are loaded on first use; no data() call is needed. They are plain tibbles without attached Stata labels: most variables are numeric (integer or double), seven datasets include character columns (such as titanic$embarked or reading$group), and disc$race / disc2$race are factors. Value meanings are always documented in codebook() and the help page.

Categorical variables and factor()

Because multi-level survey codes are kept as integers (for example titanic$pclass, individuals$job, or berkeley$department), wrap them in factor() inside model formulas so R creates dummy indicators rather than fitting a linear trend across arbitrary code numbers. Use relevel() to change the reference category of a factor (for example relevel(disc$race, ref = "White")). Also check binary codings in codebook(): most indicators are 0/1, while several survey items (such as individuals$sex or nels_data$bys74) keep their original 1/2 coding and must be recoded to 0/1 (for example I(bys74 == 2)) before passing them as the outcome of glm(..., family = binomial).

First models

A first linear regression, with the reading test at age 11 predicting the exam score at age 16:

fit <- lm(gcse ~ lrt, data = gcse)
coef(summary(fit))
#>                Estimate Std. Error    t value  Pr(>|t|)
#> (Intercept) -0.01194802 0.12642253 -0.0945086 0.9247098
#> lrt          0.59505516 0.01273006 46.7440956 0.0000000
plot(
  gcse ~ lrt,
  data = gcse,
  pch = 16,
  col = grDevices::adjustcolor("grey30", 0.2),
  xlab = "London Reading Test (age 11)",
  ylab = "GCSE score (age 16)"
)
abline(fit, lwd = 2)

A logistic regression of Titanic survival:

fit2 <- glm(
  survived ~ factor(pclass) + sex + age,
  data = titanic,
  family = binomial
)
round(exp(coef(fit2)), 2)   # odds ratios
#>     (Intercept) factor(pclass)2 factor(pclass)3             sex             age 
#>            2.78            0.28            0.10           12.16            0.97

Missing values

Survey nonresponse codes such as “8 = missing” or “99.98” were recoded to NA in version 1.0.0, so they can no longer enter a model as if they were real values. codebook() shows, for each variable, what was recoded:

cb <- codebook("nels_data")
cb[
  cb$variable %in% c("byses", "f1locus1"),
  c("variable", "na_count", "recoded_to_na")
]
#> # A tibble: 2 × 3
#>   variable na_count recoded_to_na       
#>   <chr>       <int> <chr>               
#> 1 byses           1 99.998 {missing}: 1 
#> 2 f1locus1      195 99.98 {missing}: 195

Where the data come from

Each help page ends with a Source section. LICENSE.note lists the source of every dataset, how it reached this package and why it may be redistributed. The article How the data are built on the package website describes the reproducible build.
