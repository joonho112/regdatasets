How the data are built

Source: vignettes/articles/data-provenance.Rmd
data-provenance.Rmd

Every dataset in regdatasets is a build output: it is produced by a script from a checksummed source file, never edited by hand. This article explains how, so that anyone can check and repeat it.

The pipeline

  1. Sources. The original files are kept in data-raw/source/, each with a SHA-256 checksum in MANIFEST.csv. The build refuses a file whose checksum does not match.
  2. Recipes. One small R script per dataset (data-raw/recipes/) turns the source file into the shipped tibble: it drops Stata metadata, recodes missing-value codes and applies the documented corrections.
  3. Contract. Before saving, every dataset is checked against the data contract (data-raw/CONTRACT.md): a plain tibble, the documented column names and types, and no missing-value codes left.
  4. Build. data-raw/build_all.R runs all recipes and saves data/. Two consecutive builds produce byte-identical files.
  5. Metadata. The registry and the codebook (inst/extdata/) describe every dataset and every variable. Help pages, list_datasets(), codebook() and this website are generated from them, and tests check them against the data.

Missing-value codes

Surveys such as NELS:88 store nonresponse as numeric codes, for example 8 = missing, 9 = legitimate skip or 99.98 for a missing test score. Left in place, such a code acts as a real value: one 99.98 on a scale that runs from −3 to 1.5 dominates a regression. In version 1.0.0 these codes were recoded to NA, using the survey’s own value labels and codebook:

dataset Cells recoded to NA (counted from the source file)
disc 626
nels_data 42,048

Because these counts start from the raw Stata source files, they include cells that version 0.2.0 had already turned into NA: 482 cells in disc (bys34a and bys34b codes 8 and 98) and 82 cells in nels_data (g8minor and g8lunch code 998). Relative to version 0.2.0, version 1.0.0 adds 144 new NAs in disc and 41,966 new NAs in nels_data, as reported in NEWS.md.

codebook("<dataset>") shows, for each variable, which codes were recoded. “Don’t know” answers were recoded only where the item is an ordered scale; on nominal items they remain a category.

Provenance

Each dataset’s source, the route by which it reached this package, and the basis for redistributing it are recorded in the registry and in LICENSE.note:

Dataset Provenance Basis for redistribution
alcohol1_pp verified Companion data of a published textbook, freely distributed for teaching by UCLA OARC.
berk_sub verified Published aggregate admissions table (also in base R as datasets::UCBAdmissions), expanded to one row per applicant.
berkeley verified Published aggregate admissions table (also in base R as datasets::UCBAdmissions), expanded to one row per applicant.
classdata_07 verified Simulated data created for this package; no third-party data are included.
crime verified Published textbook data of county aggregates, redistributed on CRAN (smss).
disc verified NCES public-use data; every NELS variable is in the public-use files.
disc2 verified NCES public-use data.
faculty verified Published textbook data, publicly redistributed by the publisher and Stata Press; contains no names.
gcse verified Freely downloadable teaching data, redistributed on CRAN (mlmRev) and by Stata Press.
grades probable Published textbook data, publicly redistributed by Stata Press and on CRAN (mvord).
gss_1 probable GSS public-use data, distributed by NORC for research and teaching; cited as NORC requires.
hsb_sub verified NCES public-use survey data, widely redistributed (CRAN nlme, mlmRev; Stata Press).
hsbs1 probable NCES public-use survey data printed in a textbook appendix and redistributed on CRAN (candisc).
individuals probable U.S. federal government data, not subject to copyright (17 U.S.C. 105).
instruction verified Teaching extract publicly released by the book’s authors and Stata Press, redistributed on CRAN (WWGbook).
nels_data verified NCES public-use data: all 296 named NELS variables (plus id, the NCES student ID STU_ID) are in the public-use files (checked against the NCES variable list).
penalty verified Published aggregate table, expanded to one row per defendant; also on CRAN (catdata, asbio).
pisa2000 probable OECD terms allow copying and distribution with credit to the OECD; this package is not endorsed by the OECD.
reading verified Published textbook data, redistributed on CRAN (carData, GPL).
satisfaction probable Published aggregate table of counts, redistributed on CRAN (coin).
titanic verified Historical passenger records, publicly distributed by Vanderbilt Biostatistics and redistributed on CRAN (carData, PASWR).
womenlf verified Published textbook data, redistributed on CRAN (carData, GPL) and by Stata Press.

Two datasets of earlier versions, lambert and civic_ed, were removed in 1.0.0 because no basis for redistributing them could be established. classdata_07 is a simulated look-alike of a 2007 class survey, for the same reason.
