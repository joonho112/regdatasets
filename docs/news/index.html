regdatasets 1.0.0

Version 1.0.0 rebuilds every dataset reproducibly from its source, removes missing-value codes that looked like real numbers, corrects the documentation of every dataset, and adds a registry and codebook that can be queried in R. Several changes are breaking; see the migration table below.

Breaking changes

Dataset What changed What to do
lambert, civic_ed Removed. No basis for redistributing them could be established, and both hold sensitive data on minors. Use another dataset; see list_datasets().
nels_data 41,966 nonresponse codes are now NA: NELS codes such as 8 = missing, 9 = legitimate skip and 6 = multiple response (40,145 cells); non-integer codebook codes such as 99.98 in test scores and composites (1,356 cells); and “don’t know” on four ordered items (465 cells). Results that used these variables change, and now treat nonresponse as missing.
disc 144 remaining nonresponse codes (e.g. 97 = refusal on parents’ education) are now NA. As above.
disc, disc2 race gains the level “American Indian” for 68 students who were NA before; 24 nonrespondents remain NA. Models with race now include these students.
titanic embarked was misaligned for 355 passengers in the old course file and is now taken from the titanic3 source. Results that use embarked change.
classdata_07 Now a simulated look-alike of the 2007 class survey, with the same variable names, types and codes; the original survey had no consent or release record. Code runs unchanged; numbers differ.
gcse The column pred, a stored model prediction on a different scale, was removed. Fit the model you need instead.
all Plain tibbles: Stata value labels, variable labels and format attributes were removed. ggplot2 and gtsummary used to pick up the 61 partial label attributes (e.g. titanic$age) as axis or table labels. Set labels explicitly, e.g. with labs(); see codebook().
list_datasets() Returns title and topics instead of course chapter numbers. Filter with list_datasets(topic = "logistic").

New features

  • codebook() returns the documentation of every variable of a dataset: label, type, value meanings, units, missing values, and what 1.0.0 recoded to NA.
  • list_datasets() reads the package registry and gains a topic filter.
  • Help pages generate their variable tables, titles and sources from the codebook and registry, so documentation and data cannot drift apart.

Data fixes and documentation

  • Every help page was rewritten and fact-checked against the sources. Notable corrections:
    • satisfaction is not simulated: it is Agresti’s (2002) table of 1991 GSS data, with one case added to each of its six empty cells.
    • reading is the Baumann and Jones experiment (Moore and McCabe, 1993).
    • titanic is the titanic3 compilation (Vanderbilt Biostatistics).
    • penalty comes from Radelet and Pierce (1991), covering 1976-1987.
    • womenlf comes from the Social Change in Canada Project.
    • instruction is a study of first graders’ math gains, not of reading.
    • individuals: the educ and job codes were wrong (5 and 6 were swapped in job).
    • gss_1 is the 1998 GSS; hsbs1 is a 350-student subset of Tatsuoka’s 600-student file; faculty and grades now have sources (DeMaris, 2004; Johnson and Albert, 1999).
  • LICENSE.note is generated from the registry and records each dataset’s source, route into the package, redistribution basis and provenance status.

Internal

  • data-raw/build_all.R rebuilds all datasets deterministically from checksummed source files, one recipe per dataset, and refuses to save data that break the data contract (data-raw/CONTRACT.md).
  • data-raw/audit/ documents every difference from 0.2.0 and the decision that approved it.
  • man/ and NAMESPACE are generated by roxygen2 again; their headers had been stripped, which had stopped help pages from updating.

regdatasets 0.2.0

Breaking Changes

  • naep dataset removed: The NAEP 2005 Grade 8 Mathematics dataset (17,606 x 301) has been removed because respondent-level NAEP microdata with weights are restricted-use under NCES data licensing policy. The package now contains 24 datasets. For NAEP analyses, use the EdSurvey R package to access NAEP data directly from NCES.

  • berkeley$departme renamed to department: The truncated Stata 8-character variable name has been corrected. Code using berkeley$departme will need to be updated.

  • gcse reduced from 9 to 6 columns: Removed u0, u1, and filter__ columns, which contained Stata multilevel model artifacts (placeholder values of -1e30). Remaining columns: school, student, gcse, lrt, gender, pred.

Data Cleaning

  • Sentinel missing values recoded to NA in disc (variables bys34a, bys34b: codes 8 and 98) and nels_data (82 sentinel values across multiple variables: codes 99.98, 99.99, 99.998, 998, 100).

  • titanic$embarked: Two blank strings converted to NA.

  • disc$race and disc2$race: Converted from integer codes (1-4) to unordered factor with levels: Asian, Hispanic, Black, White.

New Features

  • list_datasets() function: Returns a tibble summarizing all 24 datasets with name, dimensions, chapter mapping, and description.

  • LICENSE.note: New file documenting data source provenance and redistribution basis for each dataset.

  • inst/CITATION: Added so citation("regdatasets") returns a proper bibliographic entry.

Documentation Improvements

  • Ethical context sections added to penalty (racial disparities in capital sentencing, Radelet 1981, McCleskey v. Kemp), disc and disc2 (school-to-prison pipeline, race in school discipline), and titanic (note of respect for individuals represented).

  • Cross-references (@seealso) added linking related dataset pairs: berk_sub/berkeley, disc/disc2, hsb_sub/hsbs1, plus womenlf/carData::Womenlf overlap disclosure and berkeley/datasets::UCBAdmissions comparison.

  • gcse source citation completed: Goldstein, H., Rasbash, J., Yang, M., et al. (1993). Oxford Review of Education, 19(4), 425-433.

  • Updated disc/disc2 documentation to reflect sentinel value cleaning and race factor conversion.

Package Engineering

  • Added tibble to Imports in DESCRIPTION to ensure correct deserialization of tibble objects.

  • Expanded test suite: From 73 lines / 4 tests to comprehensive coverage of all 24 datasets (tibble class, dimensions, column names, factor levels, sentinel value absence, binary variable validation, Stata artifact absence).

  • Added NEWS.md (this file).
